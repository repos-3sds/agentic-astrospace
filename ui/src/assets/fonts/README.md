Status: canonical — the wordmark face and its licence.

`siddha-mark.woff2` is **Siddha Mark**, the face behind every "Siddha"
wordmark (`.siddha-brand`, splash, welcome, share image, website, email logo).
It is Rozha One by Indian Type Foundry, cut to printable ASCII with a headline
bar added to each letter, built by `ui/scripts/brand/build_wordmark_font.py`.

Rozha One is under the SIL Open Font License 1.1 (`OFL-siddha-mark.txt`), so
the modified face is too: free for the app, website, email and marketing, and
it must keep that licence and its own name. Copies live in
`firebase-public/fonts/` and, as a TTF, in Android `res/font/siddha_wordmark.ttf`.

It replaced Samarkan on 2026-10-29. Samarkan is shareware for personal use
only and must not come back.
